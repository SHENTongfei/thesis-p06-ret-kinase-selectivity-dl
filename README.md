# 基于深度学习的RET激酶选择性抑制剂活性预测研究

> 融合化合物分子指纹与靶点蛋白语言模型嵌入，预测化合物对RET/BTK/PLK1的高选择性档位。

## 数据一览

| 文件 | 行数 | 用途 |
|---|---|---|
| `data/p06_RetSel_main.tsv` | 2500 | 主训练集 |
| `data/p06_RetSel_ext1.tsv` | 500 | 外部验证集 1 |
| `data/p06_RetSel_ext2.tsv` | 500 | 外部验证集 2 |

数据来源：ChEMBL 公开活性数据库（pchembl 中位数切分 HIGH/MOD）
涉及靶点：BTK, PLK1, RET

## 技术路线（摘要）

化合物 **Morgan 分子指纹 (2048 维)** ⊕ 靶点 **ESM2-150M 蛋白语言模型嵌入 (640 维)**
→ **GPU 多层感知机**（动态扩缩批训练）→ 活性档位预测（HIGH/MOD 或多分类）。

- 内部验证：主训练集 80/20 分层切分
- 外部验证：ext1 / ext2 两个独立通道全量推理

## 冒烟测试成绩（GPU 实测）

| 指标 | 数值 |
|---|---|
| 主训练集样本量 | 2500 |
| 内部验证 AUC | 0.8607889146437543 |

| ext2 外部 AUC | 0.4293285016757685（n=500） |

> 冒烟级 = 快速验证管线可跑通的小规模实验。正式实验可在此管线基础上加大轮数与模型容量。
> 详细成绩见 `smoke_result.json`；完整思路见 `思路.txt`。
