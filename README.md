# 面向甲状腺癌靶向治疗的 RET 受体酪氨酸激酶配体活性深度学习推演

> 以 RET 激酶为对象，用深度学习从分子结构中推演配体活性档位，辅助 RET 重排阳性肿瘤的小分子药物发现。

## 一、方法

- **模型**：D-MPNN 有向消息传递神经网络（Chemprop 式）

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：2499 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
